# Israeli Name Meanings

מאגר פתוח ומתפתח של שמות פרטיים הנפוצים בישראל, עם פירוש קצר, מקור לשוני, אטימולוגיה, מגדר ומקורות מידע.

## מטרת הפרויקט

לבנות מאגר נתונים מסודר ואמין של שמות ישראליים — תחילה שמות יהודיים/עבריים נפוצים, ובהמשך גם שמות ערביים, דרוזיים, נוצריים ושמות ממקורות נוספים הנפוצים בישראל.

## מבנה הנתונים

הקובץ הראשי הוא `data/names.json`. קיימת גם גרסת `CSV` נוחה לעבודה ידנית.

כל רשומה יכולה לכלול:

- `name_he` — השם בעברית
- `name_en` — תעתיק/כתיב באנגלית
- `gender` — מגדר השם בישראל
- `origin` — מקור לשוני או תרבותי
- `meaning_he` — פירוש קצר בעברית
- `etymology_he` — הסבר אטימולוגי קצר
- `sources` — תוויות מקורות; ללא קישור ממוקד אין לראות בהן אימות מתועד
- `confidence` — רמת ביטחון: high / medium / low
- `status` — draft / reviewed
- `source_links` — רשימת מקורות ממוקדים: תווית, כתובת, שדות הנתמכים במקור וסוג המקור
- `research_date` — תאריך בדיקה ממוקדת; אינו מעיד על בדיקה מלאה של הרשומה
- `research_notes_he` — ממצאי הבדיקה ומגבלותיה
- `canonical_name_id` — מזהה השם המרכזי בקבוצת צורות כתיב; שדה אופציונלי

השדות החדשים נוספו בגרסה `0.2` והם אופציונליים. ב־CSV השדה `source_links` מכיל מערך JSON, ותאים ריקים מציינים שאין מידע מתועד. קובץ ה־CSV הוא UTF-8 עם BOM; בקוד Python יש לקרוא אותו עם `encoding="utf-8-sig"`.

צורות כתיב נשארות רשומות נפרדות כדי לשמור על המזהים הקיימים. כרגע קושרו שתי קבוצות: אסנת/אוסנת ודקלה/דיקלה. כאשר `canonical_name_id` חסר, אין להסיק שנבדק שאין לשם וריאנטים.

## מקורות עיקריים

התיעוד המקורי מציין נתוני הלמ״ס דרך `alumag/hebrew-names`, Wikidata, Wiktionary/Kaikki ומקורות אקדמיים. בעדכון הנוכחי נוספו אסמכתאות ממוקדות ל־11 רשומות בלבד; תוויות המקור בשאר הרשומות עדיין טעונות אימות. פירוט נמצא ב-[sources.md](sources.md).

## מצב נוכחי

נכון ל־7 באוקטובר 2026 המאגר מכיל **500 רשומות**: 204 מסווגות לזכר, 214 לנקבה ו־82 לשני המגדרים. רשומות נפרדות עשויות לייצג צורות כתיב של אותו שם; אין לראות במספר זה מספר של שמות שונים מבחינה לשונית.

כל 500 הרשומות עדיין מסומנות `draft`. בוצעה בדיקה ממוקדת של 11 הרשומות שהיו ברמת ביטחון נמוכה ונוספו להן קישורים מדויקים, תאריך ומגבלות הבדיקה. לאחר העדכון: 344 ברמת ביטחון גבוהה, 148 בינונית ו־8 נמוכה. הבדיקה אינה אימות של כל השדות בכל רשומה, ואינה אימות מלא של המאגר.

תוויות המקור הישנות, שאינן מלוות ב־`source_links`, אינן אסמכתאות שנבדקו מחדש. קישורים מדויקים יתווספו בהדרגה לאחר קריאה של המקור, ולא באמצעות יצירת כתובות משוערות. לא אומת שהמאגר מכסה את 500 השמות הנפוצים ביותר בישראל; חסרים נתוני דירוג ושכיחות.

### רמת ביטחון ובדיקה

- `high`: פירוש ישיר וברור הנתמך במקור ממוקד; רשומות ישנות ברמה זו עדיין טעונות בדיקת האסמכתאות.
- `medium`: פירוש מסויג או כזה שנתמך במקור משני אך חסרה הכרעה עצמאית.
- `low`: אטימולוגיה לא מוכרעת, פירושים מתחרים, או אסמכתה מוגבלת.
- `reviewed`: מיועד לרשומה שנבדקו בה כל שדות התוכן מול אסמכתאות מתאימות, כולל מגדר לפי שימוש בישראל. אין כרגע רשומות בשלב זה.

רמת הביטחון מתייחסת לפירוש, ואילו `status` מתייחס להשלמת בדיקת הרשומה כולה. עצם הבדיקה אינה מחייבת העלאת רמת ביטחון.

### יישומון

המאגר כולל יישומון PWA בעברית, מותאם לנייד: חיפוש בעברית ובאנגלית, סינון לפי מגדר ומקור, פרטי שם ומקורות, הוראות התקנה ושימוש ללא אינטרנט לאחר טעינה ראשונה מוצלחת.

קוד הממשק נמצא ב־`web/`. הנתונים נטענים מתוך `data/names.json`, שנשאר מקור האמת היחיד. הבנייה מעתיקה את הממשק והנתונים ל־`dist/`, ומייצרת גרסת מטמון חדשה לפי תוכן הקבצים כדי לעדכן התקנות קיימות.

```bash
npm run build
npm run dev
```

לאחר מכן פותחים `http://localhost:4173`. לפריסה ב־Vercel משתמשים בפקודת הבנייה `npm run build` ובתיקיית הפלט `dist`. ההגדרות שמורות ב־`vercel.json`. שימוש ב־Service Worker דורש HTTPS או localhost.

היישומון אינו מסתמך על שירות צד שלישי בזמן חיפוש. קישורי המקורות החיצוניים דורשים אינטרנט.

## רישוי

קוד ותוכן מקורי של הפרויקט כפופים לרישיון MIT שבמאגר. נתונים שמקורם במאגרים חיצוניים כפופים גם לתנאי הרישיון והייחוס של המקור המתאים; ראו [sources.md](sources.md). אין לראות ברישיון MIT של המאגר כמשנה את רישיון המקור של נתונים חיצוניים.
